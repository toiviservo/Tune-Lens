Display glasses do NOT expose their mic to Chrome - Meta locks it to the Meta AI app. V4 uses your phone mic for audio, HUD stays on glasses. (e.g. “Ray-Ban Meta”, “Meta Display”, “Hands-free”). If you see only “Default / iPhone Microphone”, the glasses are NOT connected as the audio input yet.

Add ?hud=1 to the URL for glasses-only mode.

Why this works this way: Browsers have NO API to push pixels directly to the Ray-Ban Meta Display. The glasses display is driven by the Meta AI app. The web pattern that works is: (1) a HUD-only page sized for the monocular display, opened from the phone, and (2) audio captured from the glasses Bluetooth mic array via getUserMedia with an explicit deviceId.
